# 合成大群友

QQ 群友头像主题合成小游戏：左右拖动投放群友头像球，两个相同头像碰到一起就合成更大一级，**合成出目标群友即胜利结算**！

- 群友池 **39 位**：就是 `profile\` 里的照片，**昵称 = 照片文件名**（不含扩展名），选择界面逐一列出；
- **合成链 13 级**：开局先选目标群友（或点「随机选择合成目标」），目标置于链顶（第 13 级），从未选中的其余群友中随机抽 12 位填 1-12 级；
- **标题恒为「合成大群友」**：无论合成哪个群友，页面标题不变；
- **合成出目标即结束**：全屏庆祝后自动弹出结算卡「合成成功！」；两个链顶球相碰不会合成新等级（无链顶彩蛋）；
- **小球按 QQ 头像方式截取**：照片居中裁方、铺满整个圆（cover），**边框统一为黑色**（512px 预生成徽章）；
- **合成图鉴**：选择界面顶部统计「已合成成功 N / 39 位群友」（跨局累计、本地保存）；只有合成出目标群友（胜利）才入鉴，入鉴的群友卡片标记「合成成功」；
- **隐藏彩蛋「群主」**：合成出群主 **Chespy** 后，选择界面点击 Chespy 会发生一些事……（详见玩法）；
- 投放解锁：合成出某级即解锁投放该级，但可投最大球不超过最大球的一半（最高投到 r=38.8 那级），更大的群友只能靠合成获得。

> ⚠️ 群友头像仅供群内娱乐，请勿用于其他用途。程序架构照搬 [bu.eltaos.top](https://bu.eltaos.top/)（「合成世界第一的大学」/ GreatUSTC 社区项目），仿照本仓库 `hecheng-da-weiyang`（合成大院系）制作。

## 🖼️ 换照片流程（重要）

游戏读取**预生成的圆形头像徽章**：

```
D:\synthesis\hecheng-da-qunyou\profile\<昵称>.jpg   ← 群友照片（你增删这里，昵称=文件名）
D:\synthesis\hecheng-da-qunyou\assets\img\round\<昵称>.png ← 生成的圆形徽章（游戏实际读取）
D:\synthesis\hecheng-da-qunyou\game-config.js       ← 生成的群友池配置
```

**增删/替换照片：把新照片放进 `profile\`（jpg / jpeg / png / bmp，任意尺寸，建议 ≥256px）→ 双击 `make-badges.bat` → 刷新页面。**

`make-badges.ps1` 会依次：

1. 扫描 `profile\` 重新生成 `game-config.js`（39+ 群友池，昵称 = 文件名）；
2. 按 QQ 头像方式逐张生成 512px 圆形徽章（居中裁方铺满 + 统一黑色描边，自动矫正手机照片的 EXIF 方向）。

须知：

- 头像描边已**统一为黑色**；`color` 字段（昵称哈希配色，金角分布色相，稳定可复现）仍用于背景主题与合成粒子；
- 手改 `game-config.js` 会在下次跑脚本时被覆盖——改配色/半径/得分请编辑 `make-badges.ps1`；
- 同名不同扩展名的照片只取第一个。

## ▶ 运行方式

- **方式一（推荐）**：本地服务器，如 `python -m http.server 8000` 或 `npx serve`，访问对应地址；
- **方式二**：直接双击 `index.html`（可玩；徽章已预生成，file:// 下显示同样正常）；
- **改代码后刷新不生效**：`index.html` 里 `style.css?v=` / `game.js?v=` / `game-config.js?v=` 是缓存版本号——改动哪个文件，就把对应版本号 +1（三个都要检查），否则浏览器继续用旧缓存。

## 🎮 玩法

- **启动进入主界面**：游戏标题「合成大群友」+ 两个选项（通过「我才是群主」后，标题与选项之间还会出现图片「被群友包围了」，见 Q7）——「开始游玩」进入正常的目标选择界面；「特殊挑战」进入挑战菜单（**主界面与特殊挑战菜单顶部都不显示**标题/游玩提示/分数那条顶栏，进入对局后才显示）；
- 「特殊挑战」选项在**任意成功合成一个群友后解锁**；未解锁时选项显示 🔒，点击弹提示「先合成一个群友再来解锁吧！」；
- 「开始游玩」后先**选择合成目标群友**（或点「随机选择合成目标」）：目标置于合成链顶（第 13 级），其余群友随机排列；棋盘背景随目标群友的主题色变为淡雅渐变；对局中可随时点「换目标」（可取消）；选择界面下方有**「回到主界面」**按钮，可随时返回主界面（进行中的对局放弃，重新开始时重开）；
- 左右拖动 / 鼠标移动瞄准，松手落下；
- 两个同级群友相碰 → 合成更大一级并得分；**只有合成出目标群友（即胜利）才记入图鉴**（选择界面统计 +1，卡片标记「合成成功」，跨局累计）；
- **合成出目标群友 → 全屏庆祝 + 金色横幅「合成大群友 / 合成成功！」→ 自动弹出结算卡，本局结束**；
- **结算卡（成功/失败共用）自上而下三个选项**：**继续合成**（回选择界面重选目标）、**再玩一次**（原目标重新开局）、**回到主界面**（返回主菜单）；
- 头像堆积越过红色警戒线 1.35 秒 → 失败（逐个爆裂动效），结算「差一点就更大了」；
- 右上角可静音 / 重开（重开需二次确认）；最高分本地保存（仅本游戏，键 `merge-game:qunyou:*`）。

### 🏆 特殊挑战菜单

- 「特殊挑战」解锁后进入菜单，每个挑战条目显示**头像**（未解锁显示 🔒）+ **挑战名称**（默认「？？？」）+ 一行小字：未解锁显示「解锁方式：？？？」，解锁后显示**该挑战的最高分**；
- **第一位：我才是群主**——解锁前头像位显示 🔒，名称照常显示，小字为「解锁方式：群主，恣意禁言群友者也」，点击不可进入；**通过一次该挑战后解锁**（显示头像与最高分，可从菜单反复进入游玩）；
- 其下为三个默认空白挑战占位（🔒 + 「？？？」+「解锁方式：？？？」，暂不可进入）；
- 「我才是群主」**每次进入/重开都重新随机选取 15 位群友排成合成链**；从菜单进入的挑战结束后回到挑战菜单，可重复游玩。

### 🥚 隐藏彩蛋：群主（Chespy）

1. **武装**：以 Chespy 为目标胜利合成一次（图鉴收入 Chespy，同时特殊挑战功能已解锁）；
2. 之后打开选择界面**点击 Chespy**：其选择框颜色变深、头像下方出现**黄底白字「群主」框**，其余 38 位群友头像下方出现**红底白字「禁言」框**（此展示态下所有人原来的「合成成功」标记一律不显示）；
3. **再点一次 Chespy** → 退出展示态，正常进入合成 Chespy 的对局；点其它群友卡片无效果（只能点「禁言」）；开局或退出后**禁言记录保留**；
4. **点「禁言」**：该群友选择框变淡、显示「已禁言」，**每次禁言都会弹出**「✕ 该群友已被禁言」，此后点击其卡片无任何效果（随机目标也会跳过已禁言群友）；**再点 Chespy 回到彩蛋可继续禁言其余群友**（已禁言的保持「已禁言」）；禁言记录跨局保存；
5. **禁言满其余全部 38 位群友** → 触发**慢速终章**：选择界面**约 2.4 秒缓慢滚动**到 Chespy（居中停留）→ **整个游戏界面（顶栏/棋盘/滑动条/其余群友）渐渐淡出，只剩 Chespy 卡片，棋盘蓝色渐变之上白幕淡入、背景完全变白** → Chespy 卡片最后渐渐淡出消失 → **界面完全变白**；
6. **特殊挑战「我才是群主」**：全白后弹出开场（`challenge/1.jpg` 头像 + 第一行「特殊挑战」+ 第二行小字宽间距「我才是群主」），开场淡出后淡入**随机 15 位群友**（不含群主；15 人已**预先排成一条 15 级合成链，链顶即秘密合成目标**；展示顺序与链序无关，无法从卡片位置猜出链条），选择界面上方显示「选择禁言一个群友」，下方三行小字（白底灰字）：「选项当中有一个是合成目标 / 如果禁言合成目标，则挑战成功 / 否则，需正常完成目标合成」；
   - 点「禁言」→ **询问是否确定禁言该群友**（可取消；确定键绿底白字）；
   - **禁言到合成目标（链顶）** → 「恭喜，挑战成功！」+ 礼花彩带（左右下三向三连爆发，配色适配白色结算背景）→ **约 2.6 秒后**弹结算（先看清合成的秘密目标球）→ **「继续」键居中** → 回到初始选择界面，**所有禁言记录清空、彩蛋永久关闭**；
   - **禁言其他群友** → 直接进入合成挑战：**15 级链按原顺序保留，仅跳过被禁言小球所在的等级**（其等级不存在：例如禁言的是 4 级，则两个 3 级直接合成 5 级；其余小球的等级与半径均不变，链最长 15 级、目标在第 15 级）；成功合成出秘密目标 → 「恭喜，挑战成功！」+ 礼花 → 「继续」清空禁言回主界面，彩蛋永久关闭；挑战对局**左上角标题变为「我才是群主」**，顶栏**「最高」显示特殊挑战内的最高分**（挑战成功/失败都会记录，本次超越时实时抬高；普通对局仍显示常规最高分）；
   - **挑战失败**（越过警戒线）→ 「很遗憾，挑战失败······」→ **「重来」（红底白字，居左）**从选择禁言小球开始、重新随机一条合成链；**「继续」（蓝底白字，居右）**清空禁言并**回到主界面**（解锁之前彩蛋可再次触发，重新禁言满即可再次进入终章）；挑战对局中顶栏「重开」「换目标」禁用；
7. **通过一次即解锁**：任意方式通过「我才是群主」后，该挑战在特殊挑战菜单中解锁（显示头像与最高分），之后可随时从主界面「特殊挑战」→ 菜单重复进入游玩（每次重开重新随机 15 人链；从菜单进入的结算后回到挑战菜单）；挑战最高分本地保存（键 `merge-game:qunyou:challenges:v1`）。
8. **第二个挑战「直到群友变成一群小猪」**：解锁流程与玩法见上方特性表 **Q7**；菜单第二位实时显示收集进度（三栏进度「🐖|🐖|🐖🐖🐖」→「快去玩解锁挑战吧，哼唧~」→ 通关后挑战名 + 最高分；头像解锁后变唱片猪动图），收集/最高分/通关标记本地保存（键 `merge-game:qunyou:pigs:v8`）。
